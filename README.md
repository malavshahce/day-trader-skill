# Day Trader workspace

A day-trading co-pilot: the `trader-*` Claude skills (scan, news, entry, exit, time machine, budget, risk, broker, alerts)
plus **Trader Desk**, a dashboard you can use from your phone.

- **How it works:** read [GUIDE.md](GUIDE.md) (also inside the app, in the Guide tab).
- **Run the web app:** `DESK_PASSWORD=choose-one python3 webapp/server.py`, then open http://127.0.0.1:8000.
- **Put it online:** see [webapp/README.md](webapp/README.md) and `render.yaml`.
- **Claude Code rules for this repo:** [CLAUDE.md](CLAUDE.md).

Nothing here places an order. Paper trading only. Not financial advice.
